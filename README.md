# 🚀 XAcademy - QA Automation con Cypress

## 📋 Descripción

Proyecto realizado como actividad de la Clase 5 de Automatización en XAcademy.

El objetivo de esta actividad fue automatizar casos de prueba sobre la aplicación SauceDemo utilizando Cypress y documentar los bugs encontrados mediante un tablero de Trello.

---

## 🛠️ Tecnologías utilizadas

* ⚡ Cypress
* 📜 JavaScript
* 🌿 Git
* 🐙 GitHub
* 📌 Trello

---

## 📂 Módulos automatizados

* 🔐 Login
* 📦 Inventory
* 🛒 Cart
* ✅ Checkout

---

## 🧪 Casos de prueba automatizados

* ✔️ Login exitoso
* ✔️ Agregado de productos al carrito
* ✔️ Validación del carrito de compras
* ✔️ Checkout exitoso
* ✔️ Validación de campos obligatorios
* ✔️ Escenarios positivos y negativos

---

## ▶️ Ejecución del proyecto

### Instalar dependencias

```bash
npm install
```

### Ejecutar Cypress en modo interactivo

```bash
npx cypress open
```

### Ejecutar Cypress en modo headless

```bash
npx cypress run
```
